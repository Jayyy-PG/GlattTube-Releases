**Dein lokaler Medien-Hub für Videos, Bilder und Sounds.**

Komprimierung, Downloader und automatischer Ordner-Organisation.

## ⬇️ Installation

1. Lade die aktuelle **`GlattTube-Setup.exe`** von der
   [**Releases-Seite**](https://github.com/Jayyy-PG/glatttube-releases/releases/latest) herunter.
2. Doppelklick und dem Installer folgen.
3. App starten – Updates installieren sich danach automatisch.

> Beim ersten Start zeigt Windows evtl. „Unbekannter Herausgeber" → **Weitere Informationen → Trotzdem ausführen**.

## ✨ Funktionen

- 🎬 **Mediathek** für Videos, Bilder & Sounds – flüssiges Raster auch bei tausenden Dateien
- 📁 **Automatische Organisation** nach Ordnern (Hauptordner → Unterordner), umbenennen, zusammenführen, ausblenden
- 👁️ **Live-Überwachung** – neue Dateien erscheinen sofort
- ▶️ **Video-Player** mit Favoriten, Tags, Audiospur-Wahl, Mini-Player (Bild-im-Bild)
- 🖼️ **Bild-Viewer** & 🎵 **Sound-Player** im Listen-Stil (Shuffle, Wiederholen, Lautstärke)
- ✂️ **Schneiden** mit Timeline-Vorschau & Live-Grössenanzeige
- 🗜️ **Komprimieren** auf eine Zielgrösse
- ⬇️ **Video Downloader** (MP4 / MP3, Qualitätswahl)
- ⭐ **Favoriten, Verlauf, Playlists** & Mehrfachauswahl
- 🔎 **Suche** über Titel, Beschreibung & Tags
- 🌑 Durchgängiges Dunkeldesign · automatische Updates

## 🔒 Daten & Privatsphäre

Alle Daten bleiben **lokal** auf deinem Rechner (`%APPDATA%/glatttube`). Es werden
keine Inhalte hochgeladen; lediglich die Update-Prüfung fragt diese Release-Seite ab.
